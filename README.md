# Rally da Diferença - FJU

Site do **Rally da Diferença**, da Força Jovem Universal (FJU).

## Tecnologias

- HTML
- CSS
- JavaScript

## Como abrir o site

1. Baixe ou clone este repositório.
2. Entre na pasta `pacote_rally`.
3. Abra o arquivo `site-rally-diferenca.html` no navegador.

## Estrutura

- `pacote_rally/site-rally-diferenca.html`: página principal
- `pacote_rally/site-rally-diferenca.css`: estilos
- `pacote_rally/site-rally-diferenca.js`: scripts
- `pacote_rally/imagens/`: imagens do site

## Observação

Os vídeos e músicas não estão neste repositório porque os arquivos são muito pesados para o GitHub.
